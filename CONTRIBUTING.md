# Contributing

Thanks for taking the time to contribute.

## Ways To Help
- Report bugs or UI issues
- Suggest improvements to content or design
- Submit fixes and enhancements

## Quick Start
1. Fork the repository
2. Create a branch: `git checkout -b feature/short-name`
3. Make your changes
4. Commit: `git commit -m "Describe the change"`
5. Push and open a pull request

## Style Guidelines
- Keep HTML, CSS, and JS readable and consistent
- Prefer small, focused changes
- Test pages in a browser before opening a PR
