# Project Images Upload Guide

Upload your project images to the dedicated folders below. Each project has its own folder where you can add multiple images.

## Project Folders & Images:

### 1. Smart Study Access
**Folder:** `images/smart-study-access/`
- Upload your images here (e.g., `1.jpg`, `2.jpg`, `screenshot.png`, etc.)
- Recommended: At least 1 image (the first one will be used as thumbnail)

### 2. Student Hustle Hub
**Folder:** `images/student-hustle-hub/`
- Upload your images here (e.g., `1.jpg`, `2.jpg`, `dashboard.png`, etc.)
- Recommended: At least 1 image

### 3. Portfolio Website
**Folder:** `images/portfolio-website/`
- Upload your images here (e.g., `1.jpg`, `2.jpg`, `homepage.png`, etc.)
- Recommended: At least 1 image

### 4. E-Commerce Website
**Folder:** `images/ecommerce-website/`
- Upload your images here (e.g., `1.jpg`, `2.jpg`, `store.png`, etc.)
- Recommended: At least 1 image

### 5. Bookshop Website
**Folder:** `images/bookshop-website/`
- Upload your images here (e.g., `1.jpg`, `2.jpg`, `bookstore.png`, etc.)
- Recommended: At least 1 image

## Recommended Image Specs:

- **Dimensions**: 400px width × 300px height (for main thumbnail)
- **Format**: JPG or PNG
- **File Size**: Under 200KB each
- **Quality**: Medium-high (clear, visible)
- **File Naming**: Simple names like `1.jpg`, `2.jpg`, `screenshot.jpg`, etc.

## Steps:

1. Navigate to each project folder in `images/`
2. Upload your project images (can be multiple per project)
3. Name them clearly (e.g., 1.jpg, 2.jpg, homepage.jpg, etc.)
4. Once all images are uploaded, let me know and I'll integrate them into the projects page

**Note:** The first image in each folder will be used as the thumbnail/featured image on the projects cards. Other images will be available for a detailed project view (if needed).
